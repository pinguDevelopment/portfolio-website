# Futuristisches Portfolio mit Discord-Integration

Sicheres, self-hostbares Portfolio (inspiriert von knabbiii.de) mit Discord-OAuth2 (PKCE), Live-Presence via Lanyard, Helmet-Security-Headers, Rate-Limiting und Redis-Sessions.

Siehe Kommentare in server.js fuer den Sicherheits-Flow. .env aus .env.example erstellen und Discord Client-ID/Secret eintragen. Deployment via Docker Compose (inkl. optionalem Cloudflare Tunnel).
